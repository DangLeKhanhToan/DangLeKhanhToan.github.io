# Project Images

Use one folder per project. Match the folder name to the `id` in `_data/projects.yml`.

Example:

```text
images/projects/vietnamese-ocr/main.jpg
images/projects/vietnamese-ocr/image_1.png
images/projects/vietnamese-ocr/image_2.jpg
```

Recommended files:

- `main.jpg` or `main.png`: primary card/detail image.
- `image_1.jpg`, `image_2.jpg`: supporting gallery images.
- Keep images under 2 MB when possible so GitHub Pages loads quickly.
