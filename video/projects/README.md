# Project Videos

Use one folder per project. Match the folder name to the `id` in `_data/projects.yml`.

Example:

```text
video/projects/vietnamese-ocr/demo_1.mp4
video/projects/vietnamese-ocr/demo_1.webm
video/projects/vietnamese-ocr/demo_2.mp4
```

Recommended files:

- `demo_1.mp4`: primary demo video.
- `demo_1.webm`: optional browser-friendly alternative.
- Keep videos short and compressed for faster page loading.
